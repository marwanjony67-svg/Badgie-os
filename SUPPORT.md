# Support BudgieOS 🦜

Welcome to the BudgieOS support page! We are building a custom operating system from scratch using C++, Assembly, and low-level system design.

## How to Get Support
If you encounter any issues, bugs, or have questions regarding the source code:
* **Open an Issue:** Go to the GitHub repository issues tab to report bugs or request new features.
* **Pull Requests:** Contributions, fixes, and optimizations are always welcome.

## System Requirements & Development
* **Assembler:** NASM (for `boot.asm`)
* **Compiler:** GCC / G++ (with `-m32 -nostdlib` flags for freestanding environment)
* **Emulator:** QEMU (recommended for testing ISO/bin builds)

Thank you for supporting **BudgieOS**! 🚀
